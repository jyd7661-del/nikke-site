고치는 유일한 경로**이므로 규칙이 엄격하다.

## A / B 규칙 — 이 작업의 전부

| 등급 | 정의 | 처리 |
|---|---|---|
| **A** | 1차 출처의 값을 **그대로 옮긴 것** (티어표 숫자, 출시일, 스킬 텍스트) | 파일에 **자동 반영** |
| **B** | 추론·해석이 한 단계라도 들어간 것 (영상 총평, 커뮤니티 체감, 역할 판정) | **제안서에만** 기록 |

- `totemRole` 신규 등록은 **언제나 B**다. 토템은 조합 후보 생성의 뿌리라 잘못 넣으면
  엉뚱한 조합이 조용히 추천된다.
- 신규 SSR의 **오버스펙 여부 판정도 B**다. 근거 규칙은 `docs/data.md`.
- `[제목 기반 추정]` 표기가 붙은 항목은 영상 자막에 접근하지 못해 **제목만 보고 판단한 것**이다.
  근거가 약하므로 그대로 믿지 말 것.

> `name_ja` 도입으로 생긴 `NAME_SUBSTRING` 경고 3건은 정상이다. `ERROR 0 / WARN 3`으로
> 갱신해야 한다. → `docs/open-items.md`

## 커밋하지 않는다

**예약 작업은 git 커밋·푸시를 하지 않는다.** 파일만 고치고, 사람이 diff를 보고 직접 커밋한다.
사람 없이 백그라운드로 돌기 때문이고, 그 실행 환경에는 자격증명도 없다.

※ 이건 **예약 작업에만** 해당한다. 일반 세션은 정상적으로 커밋·푸시한다.

## 클로드 코드에는 예약 실행이 없다

클로드 코드 자체에는 Cowork의 예약 작업에 해당하는 기능이 없다. 이관 후 선택지:

| 방법 | 설명 |
|---|---|
| **예약 작업만 Cowork에 남긴다** (권장) | 코드 작업은 클로드 코드, 주간 조사는 지금 그대로. 서로 간섭하지 않는다 |
| Windows 작업 스케줄러 | `claude -p "..."`를 비대화형으로 실행. 컴퓨터가 켜져 있어야 한다 |
| GitHub Actions | 컴퓨터와 무관하게 돈다. `ANTHROPIC_API_KEY`를 리포지터리 시크릿에 넣어야 하고, 웹 조사 도구 구성이 별도로 필요하다 |

지금 형태(사람이 diff를 보고 커밋)와 가장 잘 맞는 것은 첫 번째다.
