## 1. 버스트 순환이 먼저다

## 2. 1버스트 자리 — 「쿨감을 주는 1버」라는 기능으로 고른다

| 원리 | 출처 |
|---|---|
| 아니스 : 스타의 가치는 딜보다 수급·쿨감으로 사이클을 돌리는 데 있다 → 1·2버가 딜러보다 대체하기 어렵다 | 한국 웹 |
| 아니스 : 스타 대안: 리타 · 루주 · D : 킬러 와이프 · 세이렌 · 애장 목단 · 볼륨 · 라피 : 레드 후드(1버 대행) | 고뇨 · 스페란도 · RenGod |
| **쿨감 종류**: 리타·볼륨은 예열·스택형(첫 버스트가 늦고 타이밍이 꼬임). 루주·D : 킬러 와이프는 바로 깎인다 → 스페란도는 1버로 루주·킬러디를 권한다 | 스페란도 · 김진서 |
| **라피 : 레드 후드는 기본이 3버 딜러**다. 1버로 쓰면 3버 딜러 한 자리를 잃는다(「오버스펙」). 리타 대신 라피 1버 = 딜 −9.6%(김진서 측정) | 스페란도 · 김진서 · 한국 웹 |
| 라피 : 레드 후드 1버가 맞는 때: 다른 1버가 없을 때, 레이드에서 보스가 작열·철갑이 아닐 때(딜러로 못 쓰니 1버로 게이지) | skyjlv · 고뇨 |
| 재진입 1버(아니스 : 스타 「모두의 별」 · 티아)는 다음 단계로 안 넘어가 1버가 따로 하나 더 있어야 한다 | 김진서 |
| 쿨감 없는 애장 1버(토브 · 미란다 · 로산나)는 1버를 둘 넣는다 | 고뇨 · 한국 웹 |

## 3. 버퍼는 딜러의 대미지 공식에 맞춘다

| 원리 | 출처 |
|---|---|
| 같은 작열 3버 최상위라도 원하는 버퍼가 다르다: 마리안 : 퀸 = 공격력·코어·재장전(크라운 · 플로라 · 나가), 홍련 : 신살 = 크리·관통(민트 · 프리카 · 그레이브 · 츠바이) → **둘을 한 팀에 넣으면 버퍼가 갈린다** | 인벤 · 게임메카 · Inven Global · LDShop |
| 조건이 안 맞는 버프는 0이다: 홍련 : 신살은 확정 크리라 크확 버프 무효 · 차지·폭발 대미지가 없어 민트·프리카 효율이 낮다. 수영복 아니스와 토브는 서로를 깎는다 | 고뇨 · 김진서 |
| 짝으로만 쓰는 니케: 마스트 + 앵커 : 이노센트 메이드, 민트 + 프리카, 헬름·프리바티 + 크라운 | 한국 웹 |
| 같은 자리 후보는 등급이 아니라 **팀 총합 실측**으로 비교한다 — 홍련 단독은 크라운 + 플로라가 최고지만 3버 둘 합친 팀은 크라운 + 프리바티 75억 > 크라운 + 플로라 73.99억 | 김진서 |
| 라푼젤 : 생추어리는 크라운이 없을 때의 대체 2버(크라운 대신 넣으면 주 딜러 −약 4억). 부활을 쓰면 쿨 60초라 2버가 하나 더 필요 | Gamemeca EN |
| 딜이 아니라 버스트 수급 때문에 쓰는 니케도 있다(스노우 화이트 계열) | 김진서 |

## 5. 우리 엔진과 어긋나는 곳 (2026-11-07 기준, 고치기 전)

1. **4/5 채우기 · 폴백이 등급 합으로 1버를 고른다.** 원리는 「쿨감을 주는 1버, 그중 바로 깎이는 쪽」이다. 11-06 👎 사례에서 엔진은 아니스 : 스타 자리에 레드 후드(S, 딜러)를 넣었다. 원리대로라면 D : 킬러 와이프(즉시 쿨감)가 맞다.
2. **라피 : 레드 후드를 1버로 옮기는 답을 "자연스럽다"고 봤다**(11-07 내 B안 권고). 자료는 반대다 — 라피 : RH는 기본 3버 딜러이고, 1버 대행은 다른 1버가 없을 때의 차선이다(−9.6%). → B안 철회, A안(대체 니케가 그 단계에 선다)이 원리에 맞다.
3. **같은 팀의 3버 딜러 둘이 서로 다른 버퍼를 원하는지 안 본다**(마리안 + 홍련 : 신살). 엔진은 조건부 버프의 대상(속성·무기)은 보지만, 크리 확정 · 코어 · 재장전 같은 대미지 공식 궁합은 모른다.
4. **쿨감의 종류(즉시 · 예열 · 스택)를 구분하지 않는다.** `data/burstCdr.json`은 양(초)만 있다.
5. 토템(다섯째 · 버스트 안 씀)은 이미 다룬다(`docs/engine.md`). 쿨감형 토템(세이렌 · 루주를 오프버스트로)은 확인 필요.
6. 솔로 레이드 5팀 분배·보스 약점은 이미 다룬다. **코어·파츠 유무**는 데이터가 없다.
