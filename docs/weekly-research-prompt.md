# 주간 데이터 조사 지시서 (클라우드 예약 에이전트용)

이 파일이 **지시서 본문**이다. 예약 에이전트의 프롬프트는 "이 파일을 읽고 그대로 수행하라"
한 줄이면 된다. 그래야 규칙을 고친 것이 전부 커밋으로 남는다.

> 이전에는 지시서가 저장소 밖(`C:\Users\...\Claude\Scheduled\...`)에 있어서 버전 관리가
> 안 되고 도구가 읽지도 못했다. 2026-08-15에 클라우드 예약으로 옮기면서 안으로 들여왔다.

## 실행 환경

Anthropic 클라우드에서 **자체 git 체크아웃**으로 돈다. 사용자 PC에 접근할 수 없다.
저장소 루트에 `CLAUDE.md` · `docs/` · `reports/` · `nikke-site/`가 있고, 검사 스크립트는
`nikke-site/scripts/`에 있다. 기본 브랜치는 `main`.

## 이 작업의 목표

니케 관련 1차 출처를 훑어 데이터 파일을 최신으로 유지하고, 무엇을 왜 바꿨는지 보고서로 남긴다.

### 나무위키 라이선스 경계 (절대 위반 금지)

CC BY-NC-SA 2.0 KR이 덮는 것은 **위키 기여자가 직접 쓴 글**(평가·여담·대사·해설)이다.

  `평가`를 만나면 즉시 멈추도록 돼 있다. 이 경계를 넘지 말 것

## 1-A. 외부 웹이 막혀 있으면 **빨리 포기하고 짧게 보고하라**

2026-08-17 첫 실행에서 확인된 사실이다. **다시 조사하지 마라.**

이 실행 환경은 허용목록 방식 egress 프록시를 쓴다:
```
CCR_AGENT_PROXY_ENABLED=1
no_proxy=... anthropic.com, registry.npmjs.org, pypi.org, index.crates.io ...
```
패키지 저장소와 Anthropic만 통과하고 나머지는 전부 `curl: (56) CONNECT tunnel failed,
response 403` / `WebFetch: EGRESS_BLOCKED`다. 게임 사이트만이 아니라 en.wikipedia.org도 막힌다.
**플랫폼 정책이라 이 세션에서 바꿀 수 없다.**

그래서 막혀 있으면 이렇게 하라:

1. 출처 **한 곳만** 시험한다(prydwen 하나면 충분하다). 6곳을 다 두드리지 마라.
2. 막혀 있으면 즉시 중단하고 `reports/YYYY-MM-DD.md`에 **한 문단짜리** 보고서를 쓴다.
   제목에 `[출처 접근 차단 — 반영 없음]`을 붙인다. 프록시 진단·대조 실험을 반복하지 마라
   (이미 확인된 사실이다).
3. `WebSearch`는 동작하지만 **검색 스니펫일 뿐**이라 스킬 원문·티어표처럼 페이지를 그대로
   봐야 하는 값은 얻을 수 없다. 2차 출처 단편으로 데이터를 채우지 마라.
4. 커밋·푸시하고 끝낸다.

> 첫 실행이 이 사실을 알아내는 데 37턴 201초를 썼다. 그 조사는 이미 끝났다.

## 2. 자동 반영 규칙 — **출처 2곳 이상이 일치할 때만**

이것이 이 지시서의 핵심이다. 사용자가 직접 하나하나 검토하지 않기로 했으므로,
**신뢰도를 사람 리뷰가 아니라 이 규칙으로 확보한다.**

| 상황 | 처리 |
|---|---|
| 독립된 출처 **2곳 이상이 같은 값**이고 나머지와 충돌 없음 | **자동 반영** |
| 출처가 **1곳뿐** | 보고서에만. 반영하지 않는다 |
| 출처끼리 **갈림** | 보고서에 각 출처 값을 표로 남기고 반영하지 않는다 |
| 1차 출처의 값을 **그대로 옮기는 것**이고 다투는 출처가 없음 (출시일, 스킬 문구, 채용률 숫자) | 자동 반영 |

> **왜 이 규칙인가 — 2026-08-15 실제 사례.**
> prydwen 하나만 보고 우리 티어 8건이 틀렸다고 판단했다가, nikke.gg·game8·enikk를 더
> 대조하니 **8건 중 7건에서 prydwen이 아웃라이어**였다. 라피 : 레드후드 PvP를 prydwen만
> E(최하위)로 주는데 nikke.gg는 A, game8은 그 캐릭터를 전체 1위로 둔다.
> 단일 출처를 정답으로 전제하면 멀쩡한 데이터를 망가뜨린다.
> 자세한 기록은 `docs/open-items.md`.

### 절대 자동 변경 금지 — 조용히 망가지는 필드

값이 틀려도 에러가 안 나고 추천 결과만 어긋나는 것들이다. **출처가 몇 곳이든 보고서에만 적는다.**

- `burst` · `id` · `title` · `name_kr` · `name_ja` — 정체성. 틀리면 조합 구성 규칙이 통째로 어긋난다
  (실제 사고: 밀크 : 블루밍 바니가 버스트 1로 잘못 들어가 있었다)
- `totemRole` — 조합 후보 생성의 뿌리. 잘못 넣으면 엉뚱한 조합이 조용히 추천된다
- 오버스펙 플래그 — 판정 근거는 `docs/data.md`
- 기존 캐릭터의 **삭제**

### 신규 캐릭터 추가

## 5. git

`main`에 직접 커밋·푸시한다. 푸시하면 Vercel이 자동 배포한다.

- **`git add -A` 금지.** 파일을 이름으로 지정해 `git add`
- 커밋 메시지에 **무엇을 왜 바꿨는지와 근거 출처**를 적는다. 어느 출처들이 일치했는지 명시
- `.env.local`은 절대 커밋하지 않는다

되돌리기는 git으로 언제든 가능하다. 잘못된 값이 발견되면 그 커밋을 되돌리면 된다.
